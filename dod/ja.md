## 完成の定義

私は「完成」を、その主題の基礎知識を持つ人が容易に理解できる、明確で簡潔な説明があることと定義します。

**正本について**: このチェックリストは [`dod/deliverables-dod.json`](deliverables-dod.json) の人間向けミラーです。正本はJSONで、`scripts/sync-dod-skills.py` がJSONから1項目=1 Skill+1 Agent（`.claude/skills/dod-understanding-<id>/`、`.claude/agents/dod-understanding-<id>.md`）を機械的に生成します。JSON編集後はスクリプトを再実行し、このファイルは手動で同期してください。

各項目は括弧内のディレクトリスコープにのみ適用されます。「共通」はすべてのディレクトリに適用され、ディレクトリ固有の項目はそのトップレベルディレクトリ内にのみ適用されます（例: 機械学習の項目は `dance/` や `chess/` には適用されず、逆もまた同様）。専用の節がまだないディレクトリ（`software-engineering/`、`foods/`）は共通項目のみでカバーされます。

### 0. 共通（スコープ: common）
- [x] 理解を支える具体的な文章を記述する（単に「理解しました...」と書くだけではない）
- [x] 適用できる条件を記述する（誰が、いつ、どこで）
- [x] ライセンスや著作権に関する情報を含める

### 1. コンピュータサイエンス / 機械学習（スコープ: machine-learning）

- [x] 明確な入力と出力
- [x] 擬似コードでアルゴリズムを記述する
- [x] 使用するデータセットを説明する
- [x] 明確な計算順序
- [x] 類似アルゴリズムとの違いを記述する

### 2. ダンス（スコープ: dance）

- [x] 各ムーブの出自（判明していれば起源・考案者・年代）を記述し、出典が食い違う、または薄すぎて確証が持てない場合はその旨を明示する
- [x] 具体的な身体動作（どの関節・身体部位が、どの拍/カウントで動くか）を記述する（「グルーヴを感じて」のような曖昧な表現は不可）
- [x] 各ムーブがどのダンススタイル/ファミリー（Hip-Hop、Locking、Popping、Breakingなど）に属するかを明記する
- [x] 特定のムーブ名が依頼で指定されている場合、それぞれを名前で明示的にカバーする（汎用的なグルーヴ説明に暗黙的に含めるだけでは不可）

### 3. チェス（スコープ: chess）

- [x] 個々の駒の動かし方は説明しない（既知の前提知識とする）。戦略的な原則・概念の名称に焦点を当てる
- [x] 各原則・オープニングファミリー・エンドゲーム技法について、名称だけでなく「なぜ」それが機能するのかを説明する
- [x] 各オープニングファミリー・エンドゲーム技法が属するより広い分類（例: オープンゲーム vs クローズドゲーム、キングサイド vs クイーンサイドのエンドゲーム）を明記する
- [x] ディレクトリが宣言するゲームフェーズの範囲内に留める（`opening/` はオープニングフェーズのみ、`ending/` はエンドゲームフェーズのみ。ミドルゲーム特有の内容を混在させない）
