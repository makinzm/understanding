# Qwen3-VL-Embedding and Qwen3-VL-Reranker: A Unified Framework for State-of-the-Art Multimodal Retrieval and Ranking

## Overview

This paper introduces two complementary model series built on top of Qwen3-VL for multimodal retrieval and reranking tasks. The embedding model (bi-encoder architecture) maps diverse modalities — text, images, document images, and videos — into a unified dense representation space. The reranker (cross-encoder architecture) evaluates query-document relevance through cross-attention. Together they form a retrieve-then-rerank pipeline for large-scale multimodal search.

The framework targets retrieval applications where the query and/or document can contain images, structured visual documents (PDFs, charts), or video. The 8B embedding model achieves an overall score of 77.8 on MMEB-V2, ranking first among all models as of January 2026.

> [!IMPORTANT]
> Unlike text-only embedding models, Qwen3-VL-Embedding processes each modality through the same vision-language backbone, enabling zero-shot generalization to novel modality combinations (e.g., image query → video document) without task-specific adaptation heads.

## 1. Model Architecture

### 1.1 Embedding Model (Bi-encoder)

**Input**: An instruction string concatenated with a multimodal sequence (text tokens + image/video patches). Each image is tokenized to at most 1,280 tokens; videos are capped at 64 frames and 4,500 total tokens.

**Output**: A dense embedding vector $e \in \mathbb{R}^d$ extracted from the hidden state of a special PAD token appended at the end of the sequence.

Embedding dimensions by model size:
- 2B model: $d = 2048$
- 8B model: $d = 4096$

Matryoshka Representation Learning (MRL) is applied so the leading $d' < d$ dimensions of $e$ already form a useful lower-dimensional embedding, reducing storage cost by 50% with only 1.4% performance degradation.

### 1.2 Reranker Model (Cross-encoder)

**Input**: A concatenated sequence of query $q$ and document $d$ presented together as a single prompt, asking the model to judge relevance.

**Output**: A scalar relevance score computed from the logit difference between "yes" and "no" tokens, passed through a sigmoid:

```math
\begin{align}
  s(q, d) = \sigma\bigl(\text{logit}(\text{"yes"}) - \text{logit}(\text{"no"})\bigr)
\end{align}
```

The cross-attention between query and document tokens allows the reranker to capture fine-grained interactions that bi-encoders miss, at the cost of higher inference latency.

### 1.3 Comparison with Related Methods

| Method | Architecture | Modalities | Re-ranking |
|---|---|---|---|
| E5-mistral | Bi-encoder (text-only) | Text | No |
| VLM2Vec | Bi-encoder | Image + text | No |
| ColPali | Late-interaction | Visual docs | No |
| **Qwen3-VL-Embedding** | Bi-encoder | Text + image + video + docs | Separate reranker |
| **Qwen3-VL-Reranker** | Cross-encoder | Text + image + video + docs | Yes |

> [!NOTE]
> ColPali-style models compute token-level similarity between query and document patch embeddings (MaxSim), which is expensive at scale. Qwen3-VL-Embedding produces a single vector per item, making it compatible with standard ANN indices at much lower retrieval latency.

## 2. Training Methodology

Training proceeds in three stages, accumulating data complexity and refining the model's understanding of hard negatives.

### Stage 1 — Contrastive Pre-training

**Data**: 300 million synthesized multimodal (query, positive, negative) triplets generated by Qwen3-VL-32B covering image classification, image QA, visual document retrieval, video retrieval, and video moment retrieval.

**Loss (InfoNCE)**:

```math
\begin{align}
  \mathcal{L}_\text{retrieval} = -\log \frac{\exp(\text{sim}(q, d^+) / \tau)}{\sum_{d^- \in \mathcal{N}} \exp(\text{sim}(q, d^-) / \tau)}
\end{align}
```

where $\mathcal{N}$ contains the positive document pushed aside (hard negatives), in-batch queries, and in-batch documents. $\tau$ is a learned temperature. This stage produces model $s_0$.

### Stage 2 — Multi-task Learning

**Data**: 40 million curated and synthesized samples covering a broader task distribution including text retrieval, semantic similarity, and classification.

**Additional loss (CoSent)** for semantic textual similarity tasks encourages cosine similarity ordering to match ground-truth similarity scores:

```math
\begin{align}
  \mathcal{L}_\text{STS} = \log\!\left(1 + \sum_{(i,j): s_i > s_j} \exp\!\bigl(\text{cos}(e_i, e_j) - \text{cos}(e_i', e_j')\bigr)\right)
\end{align}
```

This stage produces the s1 embedding model and the reranker model in parallel.

**Hard negative mining** uses a two-stage pipeline: (1) recall-based retrieval with an embedding model to collect candidates; (2) relevance filtering to remove false negatives where a recalled document is actually relevant.

### Stage 3 — Distillation and Model Merging

**Data**: 4 million curated samples.

**Distillation loss**: Cross-entropy matching between the reranker's relevance distribution and the embedding model's dot-product distribution over the candidate set:

```math
\begin{align}
  \mathcal{L}_\text{distill} = \text{KL}\!\bigl(P_\text{reranker} \| P_\text{embed}\bigr)
\end{align}
```

This produces a distilled embedding model $s_2$. The final model $s_3$ is obtained by **model merging** of $s_1$ and $s_2$, reconciling the trade-off between broad task generalization (s1) and distillation-focused retrieval performance (s2).

**Implementation**: LoRA adapters are used throughout to reduce GPU memory during training while keeping the Qwen3-VL backbone largely frozen.

## 3. Matryoshka Representation Learning (MRL)

During training, all $2^k$ leading sub-dimensions of the embedding are jointly supervised. The loss is:

```math
\begin{align}
  \mathcal{L}_\text{MRL} = \sum_{m \in \mathcal{M}} \mathcal{L}\bigl(e_{[1:m]}, e^+_{[1:m]}\bigr)
\end{align}
```

where $\mathcal{M} = \{64, 128, 256, 512, 1024, d\}$. At inference time, truncating to $d' < d$ dimensions preserves most of the retrieval accuracy while halving index storage.

## 4. Quantization

Quantization-Aware Training (QAT) with Learned Step Size Quantization (LSQ) is applied after Stage 3, yielding int8-quantized models that maintain MMEB-V2 performance within 0.3 points of the fp16 baseline.

## Experiments

- **Dataset (Retrieval)**: MMEB-V2 (multimodal embedding benchmark v2 covering image, video, and visual document domains), ViDoSeek (video retrieval), MMLongBench (long multimodal documents), JinaVDR, Vidore-v3 (visual document retrieval)
- **Dataset (Text)**: MTEB Multilingual (multilingual text embedding benchmark)
- **Hardware**: Not explicitly stated; training uses LoRA to fit in available GPU memory
- **Optimizer**: Not explicitly stated
- **Results**:
  - Qwen3-VL-Embedding-8B: 77.8 on MMEB-V2 (image: 80.1, video: 67.1, visual docs: 82.4), outperforming the previous best open-source model by 6.7%
  - Qwen3-VL-Embedding-8B: 67.9 mean on MTEB Multilingual, competitive with text-only models despite multimodal architecture
  - Qwen3-VL-Reranker-8B: 80.3 average across JinaVDR and Vidore-v3, 4.1 points above the 2B variant
  - MRL with 50% dimension reduction degrades MMEB-V2 by only 1.4%
