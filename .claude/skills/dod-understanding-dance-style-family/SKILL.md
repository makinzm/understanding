# DoD item: Style/family attribution

Each move states which dance style or family it belongs to (e.g. Hip-Hop, Locking, Popping, Breaking), so it is not mislabeled across styles.

**Scopes:** dance

## Usage

Before reporting a document in one of the scopes above as done, confirm it satisfies this
check. If it does not, fix it before reporting completion.
