# DoD item: Clear calculation order

The order in which computations happen is unambiguous (e.g. via numbered steps, a pipeline diagram, or explicit sequencing language).

**Scopes:** machine-learning

## Usage

Before reporting a document in one of the scopes above as done, confirm it satisfies this
check. If it does not, fix it before reporting completion.
