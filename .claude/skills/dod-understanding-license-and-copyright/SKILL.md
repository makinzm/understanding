# DoD item: License and copyright information

The document includes license and copyright information for any quoted or referenced source material, in the Meta Information section.

**Scopes:** common

## Usage

Before reporting a document in one of the scopes above as done, confirm it satisfies this
check. If it does not, fix it before reporting completion.
