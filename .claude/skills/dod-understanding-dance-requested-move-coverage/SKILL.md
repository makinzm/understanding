# DoD item: Requested move coverage

When specific named moves were requested for a style's basic-steps document, each requested move is covered explicitly by its own name (not only implied by a generic groove description).

**Scopes:** dance

## Usage

Before reporting a document in one of the scopes above as done, confirm it satisfies this
check. If it does not, fix it before reporting completion.
