# DoD item: Game-phase scope discipline

A document under chess/opening/ stays within opening-phase concepts, and a document under chess/ending/ stays within endgame-phase concepts; middlegame-specific content does not creep into either.

**Scopes:** chess

## Usage

Before reporting a document in one of the scopes above as done, confirm it satisfies this
check. If it does not, fix it before reporting completion.
