# DoD item: Concrete sentences supporting understanding

The document contains concrete, detailed sentences that demonstrate understanding of the topic, not vague statements like "I understand X".

**Scopes:** common

## Usage

Before reporting a document in one of the scopes above as done, confirm it satisfies this
check. If it does not, fix it before reporting completion.
