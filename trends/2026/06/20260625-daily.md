## Pick Up

1. [The Red Agent POV: How it Reasoned its Way to SSRF](https://www.wiz.io/blog/red-agent-pov-ssrf)
   - Why I recommend: A concrete walkthrough of an AI red-team agent autonomously reasoning its way to an SSRF finding — directly relevant for understanding how agentic LLMs are being applied to offensive security workflows, and what failure/success modes look like in practice.

2. [How AI Is Rewriting the SecOps Playbook](https://www.wiz.io/blog/ai-rewriting-secops-playbook)
   - Why I recommend: Argues that attackers now operate at machine speed, forcing SecOps toward automation-first response — useful framing for ML engineers thinking about where agentic automation creates real operational leverage versus hype.

3. [laude Enterprise Meets the Security Graph: Wiz Integrates with Anthropic's Compliance API](https://www.wiz.io/blog/claude-wiz-integration)
   - Why I recommend: A direct, concrete example of an enterprise LLM vendor (Anthropic/Claude) wiring into a cloud security graph via a compliance API — good signal for how production LLM deployments are being governed in practice.

4. [I Threat Readiness Pillar 3: Perform AI Code Analysis Natively in Wiz](https://www.wiz.io/blog/ai-threat-readiness-pillar-3)
   - Why I recommend: Covers native AI-driven static/code analysis inside a cloud security platform — relevant for ML engineers who ship code into cloud infra and want to understand what automated review now catches before a human does.

5. [Miasma: Supply Chain Attack Targeting RedHat npm Packages](https://www.wiz.io/blog/miasma-supply-chain-attack-targeting-redhat-npm-packages)
   - Why I recommend: An active supply-chain campaign against npm packages — actionable threat intelligence for any ML pipeline or tooling stack that pulls in Node-based dependencies (e.g., JS-based data/eval tooling).

6. [Show HN: I made Google Trends for Hacker News by indexing 18 years of comments](https://hackernewstrends.com)
   - Why I recommend: A full-text search/trend index over 18 years of HN comments is a nice small-scale data-engineering case study — interesting reference point for building retrieval/trend-analysis tools over large unstructured text corpora.

7. [Political bias in AI: Where the AI models stand](https://trakkr.ai/bias)
   - Why I recommend: A live comparison of perceived political bias across AI models — worth a skim as one data point on model evaluation/alignment debates, though the methodology should be scrutinized before drawing conclusions.

8. [You can't unit test for taste](https://dev.karltryggvason.com/you-cant-unit-test-for-taste/)
   - Why I recommend: A software-engineering essay on the limits of automated testing for subjective design quality — a useful counterpoint when thinking about how far automated eval (including LLM-as-judge) can really go in assessing quality.
