## Pick Up

1. [Open-weight AI is having its Kubernetes moment](https://tobi.knaup.me/2026-07-25-open-weight-ai-is-having-its-kubernetes-moment/)
   - Why I recommend: Draws a direct parallel between the container-orchestration wars and today's open-weight model ecosystem — useful framing for an ML engineer deciding how much to invest in self-hosted inference infrastructure versus managed platforms.

2. [MCP Auto-Execution: From Git Clone to Cloud Compromise in Amazon Q VS Code Extension](https://www.wiz.io/blog/amazon-q-vulnerability)
   - Why I recommend: Documents a concrete attack chain where cloning a repo triggers unreviewed MCP tool auto-execution inside a coding assistant — critical reading for anyone wiring MCP servers into agentic dev workflows.

3. [GhostApproval: A Trust Boundary Gap in AI Coding Assistants](https://www.wiz.io/blog/ghostapproval-a-trust-boundary-gap-in-ai-coding-assistants)
   - Why I recommend: Identifies a class of trust-boundary bugs specific to AI coding assistants approving their own actions — directly relevant to evaluating the safety of agentic coding tools before adopting them on a team.

4. [Build AI Security Agents with Wiz MCP](https://www.wiz.io/blog/introducing-wiz-mcp)
   - Why I recommend: Shows a production MCP server design for exposing cloud security context to AI agents — a concrete reference architecture for engineers building their own MCP integrations.

5. [he Red Agent POV: How it Reasoned its Way to SSRF](https://www.wiz.io/blog/red-agent-pov-ssrf)
   - Why I recommend: Walks through an autonomous red-team agent's reasoning trace as it discovers an SSRF vulnerability — a rare look at LLM-driven offensive security reasoning in practice (title as fetched is missing its leading "T", a known RSS-parsing bug in the fetch script; the URL is correct).

6. [Wiz in the Verizon DBIR: How AI Acceleration and Cloud Sprawl Impact Modern Defense](https://www.wiz.io/blog/verizon-dbir-2026-ai-cloud-security)
   - Why I recommend: Summarizes DBIR-scale breach data on how AI adoption is reshaping the cloud threat landscape — good grounding data when arguing for security investment on ML infrastructure.

7. [Android May Soon Restrict On-Device ADB](https://kitsumed.github.io/blog/posts/android-may-soon-restrict-on-device-adb/)
   - Why I recommend: The day's highest-engagement HN post (830 points, 395 comments); a platform-level lockdown of ADB would affect on-device model deployment and debugging workflows for anyone shipping ML to Android.

8. [Tile's security is so bad it's a feature for stalkers](https://blog.adafruit.com/2026/03/05/tiles-security-is-so-bad-its-a-feature-for-stalkers/)
   - Why I recommend: A concrete case study of security-by-default failures in consumer IoT/BLE tracking devices — a useful cautionary reference on threat modeling for any embedded/edge ML deployment that broadcasts identifiers.
