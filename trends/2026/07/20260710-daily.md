# Daily AI & Tech Trends - 2026-07-10

## Pick Up

1. [Super Weights in LLMs and the Failure of Selective Training](https://arxiv.org/abs/2607.08733)
   - Why I recommend: Investigates how a small number of individual weights in LLMs disproportionately affect output quality, and why selective/targeted training approaches around them fail — directly useful for anyone debugging LLM fine-tuning stability.

2. [GhostApproval: A Trust Boundary Gap in AI Coding Assistants](https://www.wiz.io/blog/ghostapproval-a-trust-boundary-gap-in-ai-coding-assistants)
   - Why I recommend: Wiz documents a trust-boundary flaw specific to AI coding assistants (the class of tool this very workflow runs on) — essential reading for any team relying on agentic coding tools with auto-approval flows.

3. [MCP Auto-Execution: From Git Clone to Cloud Compromise in Amazon Q VS Code Extension](https://www.wiz.io/blog/amazon-q-vulnerability)
   - Why I recommend: A concrete supply-chain path from a cloned repo to cloud compromise via MCP auto-execution in a popular VS Code extension — a sharp reminder to audit MCP tool permissions before granting agents repo access.

4. [BiSCo-LLM: Lookup-Free Binary Spherical Coding for Extreme Low-Bit Large Language Model Compression](https://arxiv.org/abs/2607.08643)
   - Why I recommend: Proposes a lookup-free binary coding scheme for extreme low-bit LLM compression, relevant for anyone evaluating quantization strategies to run large models on constrained hardware.

5. [7440億パラメーターの巨大AI「GLM-5.2」をメモリ25GBの普通のPCで動かす推論エンジン「Colibrì」が登場](https://gigazine.net/news/20260710-colibri-glm/) (A new inference engine, "Colibrì," runs the 744B-parameter GLM-5.2 model on an ordinary PC with just 25GB of RAM)
   - Why I recommend: If accurate, this is a major efficiency claim for serving a 744B-parameter model on commodity hardware — worth verifying the underlying technique (likely aggressive offloading/quantization) against the project's own memory budget.

6. [Resample or Reroute? Budget-Aware Test-Time Model Selection for Large Language Models](https://arxiv.org/abs/2607.08665)
   - Why I recommend: Addresses a very practical production question — under a fixed inference budget, when is it better to resample from the same model vs. route to a different one — directly applicable to cost/quality tradeoffs in LLM-serving pipelines.

7. [GPT-5.6 Sol Ultra produces proof of the Cycle Double Cover Conjecture [pdf]](https://cdn.openai.com/pdf/04d1d1e4-bc75-476a-97cf-49055cd98d31/cdc_proof.pdf)
   - Why I recommend: A claimed automated proof of an open graph-theory conjecture drew 207 HN comments scrutinizing its validity — a good real-time case study in how to critically evaluate AI-generated formal mathematics claims.

8. [Claude Code・Codexとハーネスについて考えてみる](https://speakerdeck.com/oikon48/claude-codetohanesunituitekao-etemiru) (Thinking about Claude Code and agent harnesses)
   - Why I recommend: A Japanese-language deck reflecting on agent harness design for Claude Code/Codex — useful comparative perspective on harness architecture choices from outside the English-speaking dev community.

9. [How the terrorist group Boko Haram uses frontier AI](https://casp.ac/reports/ai-enabled-terrorism)
   - Why I recommend: A documented case study of frontier AI misuse by a threat actor — relevant context for anyone working on model safety, misuse mitigations, or AI policy discussions.
