# Daily AI & Tech Trends - 2026-07-13

## Pick Up

1. [Build AI Security Agents with Wiz MCP](https://www.wiz.io/blog/introducing-wiz-mcp)
   - Why I recommend: Wiz shipping an official MCP server turns cloud security posture data into something an agent can query directly — a concrete example of MCP moving from dev tooling into security operations, worth evaluating if you're wiring agents into infra workflows.

2. [GhostApproval: A Trust Boundary Gap in AI Coding Assistants](https://www.wiz.io/blog/ghostapproval-a-trust-boundary-gap-in-ai-coding-assistants)
   - Why I recommend: Documents a real trust-boundary flaw in AI coding assistants (the class of tool most ML engineers now run daily) — directly actionable for anyone auditing agentic coding tools before granting them repo or shell access.

3. [MCP Auto-Execution: From Git Clone to Cloud Compromise in Amazon Q VS Code Extension](https://www.wiz.io/blog/amazon-q-vulnerability)
   - Why I recommend: A concrete chain from `git clone` to cloud compromise via MCP auto-execution in a mainstream AI coding extension — essential reading for anyone enabling auto-run/auto-approve modes in agentic IDE tools.

4. [The Red Agent POV: How it Reasoned its Way to SSRF](https://www.wiz.io/blog/red-agent-pov-ssrf)
   - Why I recommend: Wiz's "Red Agent" series documents an LLM agent autonomously reasoning its way to an SSRF exploit — a rare public writeup of offensive-security reasoning traces from an AI agent, useful for understanding both agent capability and the resulting attack surface.

5. [Wiz in the Verizon DBIR: How AI Acceleration and Cloud Sprawl Impact Modern Defense](https://www.wiz.io/blog/verizon-dbir-2026-ai-cloud-security)
   - Why I recommend: Synthesizes Verizon's 2026 Data Breach Investigations Report through a cloud/AI lens — a good high-level pulse check on how AI-accelerated development is shifting real-world breach patterns.

6. [How AI Is Rewriting the SecOps Playbook](https://www.wiz.io/blog/ai-rewriting-secops-playbook)
   - Why I recommend: Covers how AI is being embedded into SecOps triage and response workflows — relevant context for ML engineers building or evaluating AI copilots for security teams rather than just chat/coding use cases.

7. [GhostLock, a stack-UAF that has existed in all Linux distributions for 15 years](https://nebusec.ai/research/ionstack-part-2/)
   - Why I recommend: Top HN story today (399 pts, 309 comments) on a long-lived Linux kernel use-after-free — relevant to anyone running ML training/inference clusters on Linux, since kernel-level primitives underpin container and GPU-sharing isolation guarantees.

8. [The real prices of frontier models. Tokens * Price, right?](https://playcode.io/blog/real-price-of-frontier-models)
   - Why I recommend: A practical breakdown of frontier-model pricing beyond the naive tokens×price calculation — directly useful for cost modeling when choosing or budgeting LLM API usage.

9. [Apple's new SpeechAnalyzer API, benchmarked against Whisper and its predecessor](https://get-inscribe.com/blog/apple-speech-api-benchmark.html)
   - Why I recommend: An independent benchmark of Apple's on-device SpeechAnalyzer against Whisper gives a concrete accuracy/latency data point for anyone evaluating on-device vs. cloud ASR tradeoffs.
