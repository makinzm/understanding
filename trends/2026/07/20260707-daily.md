8. [Automating AI Away](https://replicated.live/blog/away)
   - Why I recommend: A high-engagement (84 pts / 40 comments) discussion piece questioning over-reliance on AI automation — good counterpoint reading for an ML engineer immersed in the tooling.

The compliance notes recommend the `.rss` suffixed URL (`https://b.hatena.ne.jp/hotentry/it.rss`) as more reliable — the script currently fetches the non-RSS URL.
- **Wiz Blog**: The RSS feed returns its *entire* history (637 items back to December 2020), not just recent posts. For this report, entries were filtered to the last 30 days (19 items) for relevance. Separately, the script's title-cleanup logic (`str.lstrip("<![CDATA[")`) strips characters from a *set*, not a prefix, corrupting titles that start with "T" or "A" (e.g., "The Borderless..." → "he Borderless...", "AI Threat Readiness" → "I Threat Readiness"). Titles in this report were cross-checked against a direct re-fetch of the same RSS feed to restore the correct text — no invented content, only correction of a stripping-logic bug using the same authorized source.

No arXiv papers are included in this report as a result — no data was invented to fill the gap.
