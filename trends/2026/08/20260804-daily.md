# Daily AI & Tech Trends - 2026-08-04

## Pick Up

1. [Harness engineering for self-improvement](https://lilianweng.github.io/posts/2026-07-04-harness/)
   - Why I recommend: Lilian Weng's write-up on designing agent "harnesses" (the scaffolding around a model — tools, memory, feedback loops) that let an agent improve itself over time; directly useful framing for anyone building or evaluating agentic ML systems.

2. [HarnessCompass: Guiding Automatic Harness Evolution toward Generalizable and Effective Agent Harnesses](https://arxiv.org/abs/2608.01918)
   - Why I recommend: A same-day arXiv paper tackling the exact "agent harness" problem from the Lilian Weng post above, but from an automated-search angle — worth reading together to see research and practice converging on the same idea.

3. [DeepSeek V4 Flash on a Single AMD MI300X](https://github.com/ryanzhou/deepseek-v4-flash-mi300x)
   - Why I recommend: A concrete engineering writeup on running a frontier-scale model on a single AMD accelerator — actionable for evaluating AMD as a CUDA alternative for inference workloads.

4. [Qwen-CUA: Native Computer Use for (almost) Everything](https://arxiv.org/abs/2608.02352)
   - Why I recommend: Computer-use agents are moving fast; a native (non-wrapper) approach from the Qwen team is worth tracking against Anthropic's and OpenAI's computer-use offerings.

5. [Why Large Language Models Fail at Tabular Prediction](https://arxiv.org/abs/2608.02412)
   - Why I recommend: A systematic look at where LLMs underperform classical ML (gradient boosting, etc.) on tabular data — useful for calibrating expectations before reaching for an LLM on a structured-data problem.

6. [CosmosEscape: Taking Over Every Database in Azure Cosmos DB](https://www.wiz.io/blog/cosmosescape-taking-over-every-database-in-azure-cosmos-db)
   - Why I recommend: A critical cross-tenant vulnerability in a major managed database service — relevant to any team storing ML feature stores or training data in Cosmos DB.

7. [Atlas: Wiz's autonomous AI Agent for vulnerability research, ranked #1 on CyberGym](https://www.wiz.io/blog/atlas-ai-vulnerability-researcher)
   - Why I recommend: A concrete example of an autonomous agent applied to offensive security research with a benchmark result (#1 on CyberGym) — a good data point for how far agentic AI has progressed on a hard, adversarial task.

8. [Keyv and friends compromised in active Shai-Hulud supply chain attack](https://www.aikido.dev/blog/keyv-and-friends-compromised-in-npm-supply-chain-attack)
   - Why I recommend: Top-voted security story of the day (220 points, 110 comments) about an active npm supply-chain compromise — also independently covered by Wiz and a Japanese security blog below, so it's worth cross-checking dependencies against the affected package list immediately.

9. [keyv 等 複数著名パッケージへのソフトウェアサプライチェーン攻撃の概要と対応指針 (GMO Flatt Security Blog)](https://blog.flatt.tech/entry/keyv_compromise)
   - Why I recommend: A Japanese-language technical response guide for the same keyv/cacheable supply-chain attack above, with concrete remediation steps — useful complement to the English coverage.

10. [公衆Wi-Fiの接続案内画面を悪用した攻撃活動CaptiveCrunchについてまとめてみた (piyolog)](https://piyolog.hatenadiary.jp/entry/2026/08/04/183114)
